# Getting help

The question mark in the header is the help menu, which leads to these pages. $write_to

A page that ran into an error shows a reference: give it when you write, so that whoever runs
Emudoc can find in its log what happened.
$status_page
"Source code", in the help menu, leads to the code of the Emudoc your workspace runs: Emudoc is
free software under the GNU Affero General Public License, which lets anyone read, change and
share it.
